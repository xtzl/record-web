# 记录工作台（样板站）

一个**纯前端**的流水记录工具：把一串编号 + 事项 + 状态记下来，一键复制成能直接贴群里的文本，还能导出 CSV / 备份 JSON。

**没有后端、没有云端、没有账号。** 数据存在你自己这台电脑的浏览器里（localStorage），页面上传不出去。

---

## 它长什么样

- 左边：录入表单 + **要复制的内容**（边填边显示那句话，点一下「复制」就完事）
- 右边：**记录列表**（搜索、按状态/事项筛选、批量改状态、批量删除）+ 数据备份

## 一分钟上手

1. 编号框里贴编号，**多个用逗号 / 空格 / 换行分隔**：

   ```
   23423234, 234234234, 089797
   ```

2. 事项选「解绑」，然后点快捷句 **「辛苦您帮我解绑一下，运营助理确认了」**（说明和确认人自动填好）
3. 按 **Ctrl + Enter** 保存（默认每个编号单独一条，方便逐条跟状态）
4. 右侧点 **📋 复制** → 到群里 `Ctrl + V`，粘出来就是
   `23423234,234234234,089797，辛苦您帮我解绑一下，运营助理确认了`

## 快捷句（填完编号，点一下就有那句话）

表单里「说明 / 诉求」下面有一排**快捷句按钮**，点一下就自动把「说明 + 确认人」填好，不用再手打。内置两句：

| 按钮文字 | 点了之后填什么 |
| --- | --- |
| `辛苦您帮我解绑一下，运营助理确认了` | 说明 = `辛苦您帮我解绑一下`，确认人 = `运营助理` |
| `同一个连锁店下的，辛苦您帮我解绑一下` | 说明 = `同一个连锁店下的，辛苦您帮我解绑一下`，确认人 = **留空** |

流程就变成：

```
1. 编号框贴 123123,456456
2. 点一下「辛苦您帮我解绑一下，运营助理确认了」
3. 点 📋 复制  →  123123,456456，辛苦您帮我解绑一下，运营助理确认了
```

选中的那一句会**高亮**，方便确认选的是哪句；点另一句会整句覆盖（连确认人一起换，不会串味）。

### 加自己的快捷句

1. 在「说明 / 诉求」（和「确认人」）里写好这句话
2. 点 **＋ 存成快捷句** → 立刻多一个按钮，存在本机，下次打开还在
3. 自己加的句子右边有 **✕** 可删；内置的两句删不掉

## 复制（主用法：就一句话）

点 **📋 复制**，拿到的就是能直接粘出去的一句话：

```
34234234,23423432,2342342，辛苦您解绑一下，运营助理确认了
```

- **多个编号自动并成一行**（逗号分隔，不再一个编号一行）
- **没填的字段自动省略**，连同它前面的「，」一起省掉 —— 不会出现 `123，，确认了` 这种脏文本
- 只有编号、啥都没填时，就只输出 `123`

### 格式可以自己改

预览下面是「格式」框，默认模板：

```
{编号}，{说明}，{确认人}确认了
```

可用占位符：`{编号}` `{事项}` `{说明}` `{状态}` `{确认人}` `{备注}` `{日期}` `{时间}`。
改完立刻生效、自动记住（存在本机）。点「默认」回到初始模板。

例：把模板改成 `{编号}，麻烦处理一下{事项}，{确认人}` 就输出
`34234234,23423432,2342342，麻烦处理一下解绑，运营助理`。

### 备用格式（次要按钮）

| 按钮 | 内容 | 用途 |
| --- | --- | --- |
| **表格行** | `编号 ⇥ 事项 ⇥ 说明 ⇥ 状态 ⇥ 确认人 ⇥ 备注 ⇥ 时间`，一行一条记录 | 粘到 **Excel** 会自动分列；**不会**合并编号 |
| **详细清单** | 带字段名的多行明细（`【解绑】23423234` / `说明：` / `状态：` …） | 需要完整信息存档时用 |
| **复制表格行**（列表卡） | 把列表里**筛选后**的全部记录导成表格行 | 日报 / 交接 / 对账 |

## 列表怎么用

- **搜索**：编号、说明、确认人、备注都能搜；按 `Esc` 清空
- **状态胶囊**：点「待确认 3」这样的胶囊筛选，数字是实时统计
- **改状态**：每条右边的下拉框直接改，改完自动保存
- **批量**：勾选多条 → 顶部批量条出现 → 「改状态」/「删除」
- **编辑**：点「编辑」把这条载入左边表单，改完「保存修改」

## 数据在哪（重要）

- 存在**本机浏览器**里，键名 `record-workbench-v1`
- 换电脑、换浏览器、清浏览器数据 → **记录会没**，所以：
  - **导出备份 JSON**：全量备份（换设备时用「导入 JSON」恢复，重复的会自动跳过）
  - **导出 CSV**：当前筛选结果，带 BOM，Excel 直接打开不乱码
- 没保存完的输入也会自动存草稿，刷新页面不丢

## 怎么跑起来

**方式一（最简单）**：直接双击 `index.html`，用 Chrome / Edge 打开即可。

**方式二（推荐，更稳）**：起个本地静态服务

```bash
python -m http.server 8000
# 或
npx serve .
```

然后访问 `http://localhost:8000`。

## 怎么发到 GitHub Pages（跟你之前那个站一样）

1. 在 GitHub 新建仓库，例如 `record-web`（公开）
2. 把 `index.html` / `styles.css` / `app.js` 三个文件传到仓库根目录
3. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)` → Save
4. 等 1 分钟左右，访问 `https://xtzl.github.io/record-web/`

> 注意：GitHub Pages 只是**托管静态文件**，它不会帮你存数据。
> 每个人打开这个网址，看到的都是**自己浏览器里的那份记录**，互相不通。

## 想改成自己的字段？

全在 [app.js](app.js) 顶部两个数组里，改完存盘刷新即可：

```js
var STATUSES = ['待确认', '已确认', '已处理', '已驳回'];   // 状态
var TYPES    = ['解绑', '绑定', '换绑', '查询', '其他'];   // 事项
```

字段本身（编号 / 事项 / 说明 / 确认人 / 备注）在 [index.html](index.html) 的表单里，加字段的话同步在 `currentForm()`、`saveForm()`、`composeSimple()`、`composeList()` 里带上即可。

## 技术

无框架、无构建、无依赖，三个文件：`index.html` / `styles.css` / `app.js`。
控制台调试入口：`window.__RW`（可看 `records`、`state`）。

## 想升级的方向（可选）

- **多人共享 / 云端同步**：需要真后端，可选 Cloudflare Workers + D1/KV、Supabase，或飞书/钉钉多维表格 webhook
- **截图粘贴**：像 `feedback-web` 那样支持 `Ctrl+V` 贴图（要把存储换成 IndexedDB）
- **Excel 直接导入**：批量把编号列读进来生成记录
